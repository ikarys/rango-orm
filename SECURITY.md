# Security policy

## Supported versions

Only the latest minor release (currently 0.2.x) receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub private vulnerability reporting: open the **Security** tab of [ikarys/rango-orm](https://github.com/ikarys/rango-orm), then **Report a vulnerability**.

Reports are acknowledged within 7 days. This is a best-effort, volunteer project: there is no bounty and no fixed fix deadline, but confirmed issues are fixed and disclosed through a GitHub security advisory.
